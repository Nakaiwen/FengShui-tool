上傳方式
1. 先解壓縮 FengShui-GitHub-upload.zip。
2. 到 GitHub 的 Nakaiwen/FengShui-tool 專案，進入原本 index.html 所在的目錄。
3. 上傳解壓縮後的 11 個網站檔案，取代同名檔案，並提交變更。
   README-GitHub.txt 是本說明檔，可一併上傳或略過。
4. 等候 GitHub Pages 部署完成後，再重新整理網站。

請上傳解壓縮後的檔案，不要只上傳 ZIP 本身。
所有網站檔案須在同一層，不要多包一層資料夾。
不需安裝 npm，也不需建置。

網站：https://nakaiwen.github.io/FengShui-tool/
玄空頁：https://nakaiwen.github.io/FengShui-tool/#xuankong
